# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [0.1.1] - 2026-09-23

### Changed

- Remove provider-specific trigger wording and document standalone installation with the bundled license.
- Include the MIT license in the standalone skill directory.

## [0.1.0] - 2026-09-15

### Added

- Initial release: the write-like-grant skill, with the register dial from
  external email to friends-and-family texts, the greetings, sign-offs,
  punctuation, and vocabulary Grant actually uses, and seven worked examples.
